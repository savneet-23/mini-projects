# Project04: Income Tax Calculator

A simple and interactive **Income Tax Calculator** built using HTML, CSS, and JavaScript. This project allows users to enter their annual income and calculate the estimated tax payable based on predefined income tax slabs.

##Features

* 🧮 Calculates tax based on annual income.
* 💸 Uses predefined tax slabs and rates.
* 🎨 Clean and modern user interface.
* 📱 Responsive design for different screen sizes.
* ⚡ Instant calculation without reloading the page.
* 🇮🇳 Displays the tax amount in Indian Rupees (₹).

##  Technologies Used

* **HTML5** – Structures the webpage.
* **CSS3** – Styles the calculator and makes the layout responsive.
* **JavaScript** – Handles user input and tax calculations.

## 📂 Project Structure

```text
04project/
├── index.html
├── style.css
├── first.js
└── README.md
```

## 📊 Tax Calculation Logic

The calculator uses the following predefined income tax slabs:

| Annual Income           | Tax Calculation                                |
| ----------------------- | ---------------------------------------------- |
| Up to ₹12,00,000        | 0%                                             |
| ₹12,00,001 – ₹16,00,000 | 15% on income above ₹12,00,000                 |
| ₹16,00,001 – ₹20,00,000 | 20% on income above ₹16,00,000, plus ₹60,000   |
| ₹20,00,001 – ₹24,00,000 | 25% on income above ₹20,00,000, plus ₹1,40,000 |
| Above ₹24,00,000        | 30% on income above ₹24,00,000, plus ₹2,40,000 |

**Note:** These are the tax slabs implemented in this project for demonstration purposes. They are not a confirmation of the current Indian income tax rules and do not account for all applicable rebates, deductions, or other adjustments.
