**Project 03 — Love Calculator**
A fun Love Calculator built with HTML, CSS, and JavaScript that takes two names and generates a love percentage.

**Features**
Takes two names as input
Calculates a love percentage
Displays the result dynamically
Keeps the entered names visible after calculation
Pink gradient background and styled calculator card
Responsive design for different screen sizes

**Technologies**
HTML
CSS
JavaScript

📂**Project Structure**
03project/
├── index.html
├── style.css
└── first.js

**How It Works**
The calculator uses the length of the two entered names to generate a percentage using a simple JavaScript calculation.
This project is created for learning and entertainment purposes and does not represent real compatibility.
